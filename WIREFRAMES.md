## Responsive Layout

On smaller screens, the navigation and content cards stack vertically so that the pages remain readable on mobile phones and tablets.

## Development Note

The wireframes describe the planned page structure. The final website uses HTML5 semantic elements and CSS Grid/Flexbox to implement the layouts.
