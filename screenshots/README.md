# Screenshot Evidence

Save genuine screenshots of the website in this folder. The screenshots are required as evidence for the README and responsiveness criteria. They must be captured from the running website, not recreated as illustrations.

## Required responsiveness screenshots

| Filename | Viewport | What it should show |
|---|---:|---|
| home-desktop.png | 1366 × 768 | Homepage header, navigation, hero and content layout |
| home-tablet.png | 768 × 1024 | Homepage at tablet width, showing the tablet layout |
| home-mobile.png | 375 × 812 | Homepage at mobile width, including responsive navigation |
| menu-desktop.png | 1366 × 768 | Menu categories, product images, prices and search/filter |
| menu-mobile.png | 375 × 812 | Menu cards and images fitting a mobile screen |
| enquiry-form.png | 1366 × 768 | Enquiry form and estimate area |
| contact-page.png | 1366 × 768 | Contact information, form and map |

## How to capture them

1. Open the website using VS Code Live Server or the verified GitHub Pages URL.
2. Open Chrome or Edge Developer Tools with F12.
3. Toggle the device toolbar with Ctrl + Shift + M.
4. Set the viewport to the dimensions in the table.
5. Reload the page and check that the navigation, text, cards and images fit correctly.
6. Capture the visible page. For a full-page screenshot, use the browser's screenshot option in Developer Tools.
7. Save each image in this screenshots folder using the exact filename above.
8. Open each saved image to make sure it is readable before committing it.

## Keyboard focus evidence

Also capture one screenshot showing a visible focus outline on a navigation link or form control after moving through the page with the Tab key. Save it as keyboard-focus.png.
